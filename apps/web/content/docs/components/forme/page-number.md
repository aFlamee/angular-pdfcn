## API Reference

### PdfPageNumber

| Input    | Type                            | Default                    |
| -------- | ------------------------------- | -------------------------- |
| `format` | `string`                        | `'Page {page} of {total}'` |
| `align`  | `'left' \| 'center' \| 'right'` | `'center'`                 |
| `size`   | `'xs' \| 'sm' \| 'md'`          | `'sm'`                     |
| `fixed`  | `boolean`                       | `false`                    |
| `muted`  | `boolean`                       | `true`                     |

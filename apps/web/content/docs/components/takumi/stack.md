## API Reference

### PdfStack

| Input       | Type                                                    | Default      |
| ----------- | ------------------------------------------------------- | ------------ |
| `gap`       | `'none' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                | `'md'`       |
| `direction` | `'vertical' \| 'horizontal'`                            | `'vertical'` |
| `align`     | `'start' \| 'center' \| 'end' \| 'stretch'`             | `'start'`    |
| `justify`   | `'start' \| 'center' \| 'end' \| 'between' \| 'around'` | `'start'`    |
| `wrap`      | `boolean`                                               | `false`      |
| `noWrap`    | `boolean`                                               | `false`      |

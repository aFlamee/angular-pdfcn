## API Reference

### PdfCard

| Input     | Type                                 | Default     |
| --------- | ------------------------------------ | ----------- |
| `title`   | `string`                             | -           |
| `variant` | `'default' \| 'bordered' \| 'muted'` | `'default'` |
| `padding` | `'sm' \| 'md' \| 'lg'`               | `'md'`      |
| `wrap`    | `boolean`                            | `false`     |

The card body is projected content.
